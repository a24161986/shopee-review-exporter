# Shopee 评论导出器

[English](README.md)

这是一个 Chrome 浏览器扩展，用于识别当前 Chrome 窗口中已经打开的 Shopee 商品详情页，也支持粘贴商品链接批量导入，并将每个商品的评论导出为 Excel 或 JSON 文件。

## 功能

- 识别当前 Chrome 窗口里的 Shopee 商品详情标签页。
- 支持粘贴多个 Shopee 商品链接批量导入。
- 支持导出 Excel (`.xlsx`) 或 JSON (`.json`)。
- 支持设置每个商品导出的评论条数，最大 5000 条。
- 支持筛选全部评论、带图/视频评论和指定星级评论。
- 评论按时间从新到旧排序。
- 每个商品单独生成一个下载文件。
- 任务状态只显示 `等待`、`导出中`、`成功`、`失败`。
- 支持只重试失败的商品任务。

## 开发

```bash
npm install
npm run prepare:vendor
npm run verify
```

`verify` 是验证命令，通用意思是一次性跑测试和配置校验；在本项目里会运行自动测试并校验 Chrome 扩展的 `manifest.json`。

## 在 Chrome 中加载

1. 打开 `chrome://extensions`。
2. 开启开发者模式。
3. 点击“加载已解压的扩展程序”。
4. 选择项目里的 `extension` 文件夹。

## 使用方法

1. 在同一个 Chrome 窗口里打开一个或多个 Shopee 商品详情页。
2. 打开扩展弹窗。
3. 点击 `识别当前窗口商品页`。
4. 如需额外导入商品，在 `粘贴商品链接` 中粘贴链接，然后点击 `导入链接`。
5. 选择导出格式、每个商品评论条数和评论筛选条件。
6. 点击 `开始导出`。
7. 在任务列表里查看 `成功` 和 `失败` 状态。
8. 如有失败任务，点击 `重试失败项`，只重新导出失败商品。

## 注意事项

- 扩展只识别当前窗口已打开标签页的 URL，不会扫描网页正文、推荐商品或页面里的其他链接。
- Shopee 页面显示的评论数量可能包含仅星级评分、无文字内容或平台隐藏的评论；实际导出数量取决于 Shopee 评论接口返回的数据。
- 当前分页逻辑会在短页后继续请求下一页，直到达到设置数量或接口返回 0 条。
- 如果导出数量仍不足设置值，通常表示接口没有继续返回更多可导出的评论。
